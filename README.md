# OrangeHRM Login Automation

Automation testing untuk fitur Login pada website OrangeHRM menggunakan Cypress

## Test Case

Automation dibuat berdasarkan 12 test case fitur Login:

- TC-LOGIN-001 - Login dengan username dan password valid
- TC-LOGIN-002 - Login dengan username tidak valid
- TC-LOGIN-003 - Login dengan password tidak valid
- TC-LOGIN-004 - Login dengan username dan password tidak valid
- TC-LOGIN-005 - Login tanpa mengisi username
- TC-LOGIN-006 - Login tanpa mengisi password
- TC-LOGIN-007 - Login tanpa mengisi username dan password
- TC-LOGIN-008 - Login dengan username yang memiliki karakter tidak valid
- TC-LOGIN-009 - Login dengan username yang memiliki spasi di awal dan akhir
- TC-LOGIN-010 - Login dengan username menggunakan huruf kecil
- TC-LOGIN-011 - Mengakses Forgot your password
- TC-LOGIN-012 - Login dengan password yang mengandung karakter khusus
